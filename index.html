Возможности

Всё в одном пакете

Построено на Reticulum Network Stack — сети, где криптография заложена с нуля, для медленных и ненадёжных каналов связи.

📡
LoRa-сеть
Подключай RNode по USB или Wi-Fi. Дальняя зашифрованная радиосвязь — без инфраструктуры и без лицензии.
🏠
Мост в Home Assistant
Отправляй команды в HA по радиоканалу LoRa. Запускай автоматизации откуда угодно — даже полностью автономно.
🔒
Анонимная сеть I2P
Соединяй два шлюза анонимно, без публичного IP. Настройка туннеля — в один клик из дашборда.
🌐
Узел Nomadnet
Размещай страницы в сети Reticulum. Встроенный браузер, редактор страниц, Python-скрипты с планировщиком cron.
⚙️
Веб-дашборд
Полноценное управление на порту 8081. Сервисы, живые логи, редактор конфигов, обновления. Без SSH.
🤖
LXMF-бот
Встроенный бот с командами /ping, /status, /info. Расширяется — добавляй свои обработчики через MQTT.

Комплект

Что внутри

Полный исходный код на GitHub — клонируй и запускай на любом устройстве с Debian/Ubuntu.

install.sh
Установка в одну команду. Ставит зависимости, настраивает systemd-сервисы, спрашивает данные MQTT.
Веб-дашборд
Flask-интерфейс на порту 8081. Панели Services, Configs, Logs, Monitor, RNode, I2P, Nomadnet, System.
LXMF Bridge бот
noema_lxmf_bridge — мост LXMF ↔ MQTT со встроенными командами и полной интеграцией Home Assistant.
Все сервисы настроены
rnsd, noema_lxmf_bridge, i2pd, nomadnet, rbrowser — уже готовы как systemd-юниты.
Полная документация
README на русском и английском — установка, настройка, сценарии использования, решение проблем.
Backup & Restore
Резервная копия всех конфигов, страниц, скриптов и ключей идентичности в один клик. Восстановление из дашборда.
Требования: Debian / Ubuntu · Python 3.10+ · root-доступ · x86_64 или ARM (Orange Pi, Raspberry Pi, мини-ПК…)
